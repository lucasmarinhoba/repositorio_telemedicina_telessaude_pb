# Repositório de Apoio à Telemedicina e Telessaúde da Paraíba

Portal público destinado a centralizar, organizar e facilitar o acesso a informações relacionadas à telemedicina, telessaúde e saúde digital na Paraíba.

## Sobre o Projeto

Este portal tem como finalidade atuar como um repositório de apoio e organização da informação, não substituindo sistemas oficiais, mas sim direcionando o usuário para as fontes e serviços apropriados.
